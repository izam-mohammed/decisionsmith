# Examples

Every example is a short runnable script with synthetic data. Each folder has a README with the code and how
to run it. `DS_OFFLINE=1` runs any of them without keys or network (LLM answers come from a local stand-in),
which is also how CI runs every one of them.

This page is generated by `scripts/gen_gallery.py` from each folder's `meta.yaml`.

## Starters

| example | what it shows | needs |
|---|---|---|

| [Golden dataset](01-starters/golden/) | ds.golden picks the texts most worth labelling (from a harness log or a list), the main LLM labels them, and a held-out split keeps evaluation honest. | `laya`, `anthropic` |
| [Jev teacher, Laya student](01-starters/jev-teacher/) | TypeSafe's hosted Jev labels, Laya learns; status() compares them. | `laya`, TYPESAFE_API_KEY |
| [Local only (Ollama + Laya)](01-starters/local-only/) | An Ollama teacher and a Laya student; nothing leaves your machine. | `laya` |
